# Visual references

The three PNGs in this folder are the user's supplied original reference images, included so Claude can inspect them locally. Filenames identify the reference role.

- `desktop-warm.png`: primary dashboard frame, panel layering, type hierarchy and calm warm palette.
- `desktop-table-blue.png`: data table spacing, toolbar, subtle separators, status pills and pagination.
- `mobile-panels.png`: mobile panel hierarchy, readable opaque cards and compact navigation.

Use 02-DESIGN.md to resolve the visual direction. These references are aesthetic guidance, not artist content, logos, sample data or feature requirements. Do not use these full screenshots as website backgrounds. The older brief's Donezo green/no-glass direction is superseded for admin styling; public site preservation still stands.
