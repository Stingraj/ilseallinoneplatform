# Agent working agreement

This is a planning pack, not an installed skill or an automatic multi-agent configuration. Role documents under docs/ilse/roles are narrow execution instructions. One Claude session can take each role in turn; this is the token-efficient default.

The implementation coordinator owns routing, global studio tokens, package files, database changes, shared contracts and final integration. A role may edit its module only after confirming file ownership. Parallelism is optional and must never duplicate full repository audits or overlapping writes.

Do not overwrite root AGENTS.md. Its current Next.js block requires reading relevant installed documentation before code changes. Preserve that requirement and any other local rules.

Required handoff, maximum about 250 words: task IDs; evidence paths; files changed; contract changes; commands/results; blocker; next action. No repeated architecture essays.

All roles enforce owner access, consent, real data, existing-route compatibility, no live email during tests, and preservation of public website design. Reviewers inspect behavioral changes, not just screenshot similarity.
